# Админ-панель ВАГН

Адрес после публикации: `https://world-academy.vercel.app/admin.html`.

Панель управляет всеми разделами `data/site-content.json`: историей, учредителями, руководством, академиями стран, документами и полным архивом, новостями, фотогалереей, RU/EN/KZ-текстами и контактами. Поддерживаются добавление, дублирование, сортировка, удаление, загрузка файлов, локальный черновик и резервные копии.

## Переменные Vercel

- `ADMIN_PASSWORD` — пароль клиента;
- `ADMIN_SESSION_SECRET` — отдельная случайная строка не короче 32 символов;
- `GITHUB_TOKEN` — fine-grained token с правом Contents: Read and write для репозитория;
- `GITHUB_REPOSITORY` — `daniyalzhussupoff/itf-wams`;
- `GITHUB_BRANCH` — `main`.

Секреты нельзя добавлять в репозиторий или клиентский JavaScript. Сессия подписывается на сервере и действует 12 часов. Публикация создаёт коммит в GitHub, после чего Vercel запускает обычный деплой.

## Локальная проверка

Обычный статический сервер показывает публичный сайт с `data/site-content.json`. Для входа и публикации из локальной админ-панели нужны Vercel Functions:

```bash
vercel dev
```

Локальные секреты задаются в `.env.local`; файл не коммитится. Файлы через панель ограничены 3 МБ. Более крупные PDF следует добавлять напрямую в `assets/` через Git.
